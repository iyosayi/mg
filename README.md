## Running the Server
1. Install ```run-rs``` from npm, make sure you install globally using ```npm install -g run-rs```
2. After installation, run this command ```run-rs -m -k``` to start the replicaSets.
3. When the ```run-rs``` command has started, then open another terminal and run ```npm run dev```
4. This will bring the server up.
